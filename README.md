# 🏡 GharYatra

GharYatra is a full-stack property discovery and management web application that allows users to explore properties, manage property listings, and interact with location-based features.

The application is built using **React + Vite** on the frontend and **Django REST Framework** on the backend, with **PostgreSQL** used for production data storage and **Google Maps** for location-based functionality.
